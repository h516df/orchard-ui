# 视觉基础 · 0.2

具体控件外形以[Apple视觉基线](APPLE_VISUALS.md)为准。用户拒绝0.1的Material默认外观，不能仅以配色、圆角相近就判定达到要求。

## 想要的感觉

清楚、安静、自然，信息层级比装饰更先被看见。参考苹果界面的大标题、分组内容、留白与操作连续性，在安卓上保留系统返回、权限、选择器、键盘和安全区域习惯。参考来源是 [Apple HIG](https://developer.apple.com/design/human-interface-guidelines)；本库为独立设计，不复制其素材。

同一套系统可以长出不同的产品：记录类适合纸感绿，工具类适合清透蓝，生活类可以暖杏，阅读类可以墨色。不要因为共用组件就把每个首页都做成同一排卡片。

## 唯一变量源

`tokens/orchard.json` 是共享源，`tools/generate_tokens.py` 输出四种语言。项目新增皮肤时补充所有语义与深色值，跑对比度检查；不只换主色。

| 类型 | 默认值 | 使用方式 |
| --- | --- | --- |
| 间距 | 4 / 8 / 12 / 16 / 24 / 32；页面边距 20 | 4 为细节、8–12 为同组、16 为内容、24–32 为组间 |
| 字阶 | 13 / 15 / 17 / 22 / 34 | 说明 / 标签 / 正文 / 页内标题 / 大标题 |
| 圆角 | 胶囊按钮；内容组 20、面板 32 | 只在相应层级使用；嵌套控件避免层层大圆角 |
| 最小触控 | 48 逻辑像素 | 图标可画 20–24，点击区域保持 48；字体放大后允许增高 |
| 阅读宽度 | 最大 640 | 宽屏居中，大量正文不横贯屏幕 |
| 动效 | 120 / 220 / 320 ms | 按压反馈 / 状态切换 / 页面连续性；系统减少动态效果时减少或取消 |

逻辑尺寸在 Compose 中为 dp/sp，Flutter 为逻辑像素，RN 为布局单位；Web 字号用 rem，不能将 px 字号强制锁死。生成 CSS 的数字变量供布局使用，字体类自身使用 rem。

## 色彩和状态

- `background` 是页面底，`surface` 是内容层，`surfaceMuted` 是次级填充。
- `text` / `textSecondary` 分主次；说明文字也需要可读，不用极浅灰制造层次。
- `primary` 用于主要操作、选中与链接；与 `onPrimary` 成对使用。
- 轻强调背景使用 `primaryContainer` / `onPrimaryContainer`。
- 危险操作与错误使用 `danger`；正常支出、零记录、尚未配置不是错误。
- 分隔线 `divider` 只做装饰；必要的焦点/边界使用达到对比度的 `outline`，输入不使用Material浮动标签/缺口描边。
- 禁用必须有可操作路径或解释，不能把必需按钮永久灰掉让用户猜。

默认 8 个方案的正文/说明与常用背景、按钮/容器文字对比度检查目标至少 4.5:1；关键控件边界/焦点至少 3:1。透明材质、图片上文字和项目自定义颜色必须另测。

## 字体与中文

使用平台系统字体，不捆绑 Apple 的 San Francisco 字体。中文正文建议 17 起，阅读正文 19 起；保持可调，遵循系统字体缩放。长标题自然换行，说明文字不为凑齐卡片高度强制截断。金额、单位和时间分清层级；数字格式与舍入属于业务层。

轻粗标题和常规正文建立层次，不整页加粗。行距按语言和用途调节；阅读示例 1.7，表单说明约 1.5。有长英文、链接或用户生成标题时，允许合理换行。

## 材质、图标和动效

默认实色分层和细分隔线，阴影只表示浮起。半透明只用于需要表达前后层关系的栏或面板，先测对比度和低端安卓性能。0.2的Compose(API31+)、Flutter、Web提供导航背景模糊与不透明回退；RN默认实色，可由宿主传入模糊层。详见Apple视觉基线。

图标表示操作时必须有可读标签；装饰图标不重复朗读。Compose 附带的简单线图标为原创几何路径，其他适配层使用官方控件/图标或文字。复杂图标库按 [选型表](STACK_CHOICES.md) 接入并保留许可。

动效帮助理解“从哪里来、现在处于什么状态”。不要为每张卡片循环呼吸或漂浮。骨架屏默认静态；耗时操作有文字状态，不以无限转圈代替错误处理。静态截图不能证明顺滑，设备帧率与中途操作需运行验证。
