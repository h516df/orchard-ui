## OUI-001 · 跨项目苹果风 UI / UX 复用库

用户原话摘录：“你决定呀，多搞点，放到我的 GitHub 仓库里面，方便我后续开发复用，私有仓库吧”；补充：“不一定 Kotlin + Jetpack Compose 这个”。

场景：多个安卓项目经常调整 UI / UX，希望共享设计与实现资源；后续项目技术栈可变化。

完成条件：

1. 创建并读回确认私有 GitHub 仓库，源码与资料长期保存。
2. 框架无关的视觉变量、UX模式和页面配方可复用，不绑定Compose。
3. 提供实际可检查的多框架代码与接入示例，覆盖范围如实列出。
4. 关键交互、主题/字号与构建有可追溯验证；未覆盖真机行为单列。
5. 仓库自带开发助手入口与交接；不自动改写其他App。

状态：0.1源码和检查已交付，但用户明确不接受其视觉，不能把测试通过当作视觉验收。当前由OUI-002纠正。准确仓库/提交与验证见 [HANDOFF](../HANDOFF.md)、[VERIFICATION](VERIFICATION.md)。

代理选择：Orchard/果园名称；共享tokens + Compose/Flutter/RN/Web适配；4套配色、15类UX模式、12类页面配方；这些是授权范围内的实现选择，不代表用户指定了每个组件。
