# 页面配方

这些是信息组织与交互配方，不等于每个框架都已经提供完整页面。代码覆盖见 [组件目录](COMPONENTS.md)，状态规则见 [UX_PATTERNS](UX_PATTERNS.md)。

| 场景 | 从上到下的结构 | 关键边界 |
| --- | --- | --- |
| 首页概览 | 一句标题 → 一个核心事实 → 一个主要动作 → 最近内容 → 低优先级摘要 | 无数据时解释来源，不用假数字填充 |
| 记录时间流 | 大标题/日期 → 搜索 → 少量筛选 → 按真实时间分组的条目 → 输入入口 | 日期由可刷新状态提供，返回保留位置 |
| 书架/收藏库 | 大标题 → 搜索 → 网格/列表切换 → 稳定封面或文字卡 → 导入 | 没封面也有良好排版，不能先强迫找图片 |
| 阅读详情 | 顶部返回/更多 → 有限宽正文 → 按需显示的工具 | 默认沉浸，正文不被永久按钮覆盖 |
| 编辑页 | 返回/标题 → 主输入 → 附件/辅助信息 → 提交 → 就地错误 | 草稿保护、IME 滚动、失败保留 |
| 偏好设置 | 大标题 → 显示/行为组 → 资料组 → 关于组 → 危险区 | 高频直接用，低频逐层展开 |
| 导入预览 | 来源 → 内容范围 → 警告/冲突策略 → 样例预览 → 确认/取消 | 预览不写正式库 |
| 搜索结果 | 搜索输入 → 当前筛选 → 命中数量 → 结果 | 无结果允许清除筛选，保留查询 |
| 金额与时间 | 核心数值及单位 → 计算口径 → 分项 → 修改条件 | 未配置与结果为零分开，计算由业务层负责 |
| 媒体档案 | 原比例封面 → 名称 → 可选摘要 → 按需展开字段 → 操作 | 不把每个字段变成必填，原件/缩略图区分 |
| 检查更新 | 当前版本 → 主动检查 → 新版说明 → 下载/校验/安装状态 | 应用身份、证书与数据保留归原更新器 |
| 首次使用 | 一句用途 → 最小必要输入 → 立即得到结果 → 可选完善 | 能跳过的就跳过，不做五页欢迎轮播 |

## 如何用

先写出“用户来到这里要完成的一个动作”，选择配方后删掉不需要的模块。每屏尽量只有一个高强调的主要操作，其余动作降一级。长内容允许自然增长，不能用固定高度把大字号裁掉。

窄屏用单列；宽屏按任务选择两栏主从或居中阅读，不能单纯把手机卡片拉宽。底部导航承载顶级目的地；卡片不是所有信息的默认容器，正文列表可以只用留白和分隔线。

用 [项目简报](../templates/PROJECT_UI_BRIEF.md) 记一次设计取舍，再用 [审查表](../templates/UI_REVIEW.md) 检查关键状态。不要为填模板而增加项目里不存在的账号、同步、支付或权限流程。
