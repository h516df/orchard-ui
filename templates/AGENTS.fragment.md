## UI / UX 复用入口

本项目界面参考私有 [h516df/orchard-ui](https://github.com/h516df/orchard-ui)。开始 UI 任务先读取其 README、FOUNDATIONS、UX_PATTERNS 与 COMPONENTS，再核对本项目实际技术栈、当前主题、相关 PR 与本地约定。访问不了时沿用已有项目规则，不假称读过。

- 苹果风是视觉方向，不锁定 Kotlin/Compose。优先保留本项目技术栈、官方控件和已有能力。
- 从 Orchard 选适配层与页面配方；固定使用的版本/提交。不要把其他项目的品牌与数据逻辑复制进来。
- 配色、字号、间距、圆角和状态用语集中管理；项目专属皮肤在项目内维护。
- 保存失败保留草稿，返回/关闭保护未保存内容，导入先预览，错误可恢复；实现范围按本项目实际功能决定。
- UI 修改验证浅深色、窄屏/200% 字号与关键交互。真机行为单列，截图不能证明真实数据写入或动画性能。
- 不因接组件库改变应用 ID、正式签名、存储、更新路径或原有功能；不得自动批量迁移其他仓库。

此片段由代理在目标项目获授权时保留原规则后接入；GitHub 中保存入口不等于账户级指令或所有会话自动加载。
